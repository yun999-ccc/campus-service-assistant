# SQL探案室 · 2.0

用库存、退款、权限审查三个虚构案件练习查询和证据判断。每案包含观察、定位、验证三个任务，共九项。原生 HTML/CSS/JavaScript，sql.js 1.13.0 在独立 Web Worker 中真实执行 SQLite 查询。

## 网站

https://yun999-ccc.github.io/campus-service-assistant/sql-detective/

可用 `#inventory/0`、`#refund/1`、`#access/2` 定位任务；`?mode=practice&sample=1` 选择练习规模和B组样本。

## 本版功能

- 引导、练习两种数据规模，每种有A/B/C三组可复现样本。每次提交SQL在三组数据中核对，而不是只比一份固定答案。
- 库存练习包含20件商品、170条流水；退款练习包含120笔订单、192条退款；权限练习包含12个常设角色和1个临时角色、76条实际授权、48条批准项。
- 无流水、正负抵消、失败/处理中/分笔退款、重复授权台账和新角色等边界记录。所有金额以整数分存储，图表换算为元。
- 独立证据表浏览：分页、过滤、表关系及字段释义，不覆盖调查结果。
- 单条SELECT、真实SQL错误、最多显示200行、1.5秒超时终止并重建Worker；最多6000字符；输入限定与SQLite只读标志两层约束。
- 三组验证反馈；引导模式显示缺少/多出行数，挑战模式收起线索、参考及差异数。
- 库存/退款对照条形图、权限矩阵，与实际查询结果对应，只有当前查询通过三组验证后才显示。
- 编辑后标记旧结果过期；本次作答与历史完成分别显示。选项顺序在新尝试中随机、当前尝试内稳定，不靠固定位置答题。
- 可选仅保存本机完成标记，可清除；不持久保存SQL。TXT复盘包含实际提交、三组核对、参考使用、本次判断和历史记录。

## 能力边界

当前是 **SQLite演练，不是真实MySQL服务端**。共享语法可用于SQL学习，MySQL专属语法、实际GRANT/REVOKE和系统权限核验不在本版范围。权限案例仅比较模拟台账。

辅导是本地规则，**尚未接入Coze或大模型API**。三组前端样本可以发现部分错误逻辑与硬编码答案，但不是保密测试集，不能证明所有数据下均正确，也不提供考试防作弊能力。参考查询只是一种解法，按结果多重集合核对：忽略行序、不忽略重复行、字段类型及列顺序，不强制别名。

数据为固定核对时点的虚构快照，异常只是复核线索，不能直接判断退款责任、偷盗或真实违规。记录数不是风险评分。

## 隐私与存储

查询在本地执行，不上传、不埋点。默认不持久保存；勾选“在本机保存完成记录”后，仅在本网站localStorage保存数据版本和完成任务键。SQL文本、查询结果、个人资料不写入该记录。取消勾选或点击清除可删除保存。浏览器拒绝存储时仍可训练。下载复盘由用户浏览器保存，可能包含其输入的SQL；不要输入真实账号、密钥或客户资料。静态资源访问日志由GitHub Pages管理。

## 本地运行与测试

在父目录启动 `python3 -m http.server 4193`，访问 `http://127.0.0.1:4193/sql-detective/`。不能通过file协议双击打开Worker应用。

在本目录执行 `node --test tests/*.test.mjs`（Node.js 22或更新）。自动测试使用内置模块和随附引擎，涵盖九任务、两种规模、三组数据，参考SQL与独立JavaScript业务规则交叉比较，以及状态回归、硬编码/错误连接/错误口径、只读与截断保护。界面还需浏览器验收。

## 文件

- data.js：可复现数据及独立业务规则，测试不依赖UI中写死的预期行。
- cases.js / tasks.js：案件说明、九个任务及参考解法。
- model.js：当前提交、编辑状态、选择与历史完成快照。
- query-core.js / worker.js：隔离执行、结果差异、三组核对。
- visuals.js / styles.css：自制SVG插画、实际查询图表、浅色工作台。
- app.js / index.html：原生控件与交互。
