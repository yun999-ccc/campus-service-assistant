# 校务通 校园办事与求助

一个面向学生的校园服务网页原型，提供办事导航、准备清单与校园网逐步排查。

[打开公开体验网站](https://yun999-ccc.github.io/campus-service-assistant/) · [项目源码](https://github.com/yun999-ccc/campus-service-assistant)

![网页实际运行预览](assets/preview.jpg)

## 可以体验什么

- 描述学生证、奖助申请、校园账号或校园网问题，按本地规则进入对应服务。
- 查看行动步骤、勾选确认事项，保存清单并在同一浏览器继续使用。
- 通过网络排查分支记录检查过程，生成和复制求助摘要。
- 按类型和关键词筛选服务，支持 WiFi、助学金等搜索别名。
- 使用桌面或手机访问，支持键盘操作和减少动画偏好。

## 当前范围

这是学生项目体验版，并非学校官方系统。尚未接入大模型、学校系统或正式知识库。流程为演示示例，不代表学校的现行要求；受理地址、费用、时限及申请资格尚未核实，不作猜测。

输入在浏览器内处理，没有后端提交。清单保存在 localStorage 中，仅限当前设备和浏览器；浏览器清理数据会清除清单，存储受限时会提示。请勿输入密码、验证码或完整个人证件信息。敏感格式提示不能替代完整的数据保护系统。

## 本地运行

运行环境：Python 3。网站无需安装前端依赖。

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。

可选测试环境：Node.js 18 或更新版本。

```bash
node --check app.js
node --check logic.js
node --test tests/logic.test.cjs
```

## 公共部署

GitHub Pages 从 main 分支的根目录发布。所有运行文件和校园照片都在仓库中，使用相对地址，适用于仓库子路径。

页面加载不依赖模型服务、第三方字体或图标 CDN。外部网络仅用于访问网站及主动打开图片来源链接。公开网址不要求访问者登录 GitHub，也不依赖开发者电脑开机。

GitHub Pages、访问者网络以及浏览器会影响可用性；不承诺永久在线或百分之百可用。保留仓库及 Pages 配置即可持续提供静态网页。
