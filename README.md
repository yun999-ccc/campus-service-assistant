# 校务通 校园办事与求助

一个面向学生的校园服务网页原型，提供8项服务的办事导航、准备清单、设施报修摘要与校园网逐步排查。

[打开公开体验网站](https://yun999-ccc.github.io/campus-service-assistant/) · [项目源码](https://github.com/yun999-ccc/campus-service-assistant)

![网页实际运行预览](assets/preview.jpg)

## 可以体验什么

- 描述学生证、奖助申请、校园账号、校园网、在读证明与成绩单、请假返校、宿舍报修或图书借阅问题，按本地规则进入对应服务。
- 查看行动步骤、勾选确认事项，保存清单并在同一浏览器继续使用。
- 通过网络排查分支记录检查过程，生成和复制求助摘要。
- 按证件与学业、申请与手续、生活与设施、账号与网络四类筛选8项服务，支持 WiFi、助学金、续借等搜索别名。
- 宿舍设施报修按类型记录现象，生成摘要；安全风险提示转人工，不会自动提交报修。
- 使用桌面或手机访问，支持键盘操作和减少动画偏好。

## 当前范围

这是学生项目体验版，并非学校官方系统。首页“打开 AI 助手”连接已发布的 [Coze 智能体](https://www.coze.cn/store/agent/7694916887939465251?bot_id=true)，使用豆包 2.0 pro 和真实的“开始 → 知识检索 → 大模型 → 结束”工作流。知识库含学校公开历史资料摘要与项目安全边界，不能证明学校现行规定。未接入学校业务系统，不查询审批、判断资助资格或提交报修。

网页输入框仍采用本地规则导航；模型对话在 Coze 页面进行，可能需要登录并受平台额度和可用性影响。没有前端 API 密钥或静态网页直连模型接口。Coze 中提交的问题由平台处理，应遵守其隐私政策，请勿发送敏感信息。

输入在浏览器内处理，没有后端提交。清单保存在 localStorage 中，仅限当前设备和浏览器；浏览器清理数据会清除清单，存储受限时会提示。请勿输入密码、验证码或完整个人证件信息。敏感格式提示不能替代完整的数据保护系统。

## 本地运行

运行环境：Python 3。网站无需安装前端依赖。

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。

可选测试环境：Node.js 18 或更新版本。

```bash
node --check app.js
node --check logic.js
node --test tests/logic.test.cjs
```

## 公共部署

GitHub Pages 从 main 分支的根目录发布。所有运行文件和校园照片都在仓库中，使用相对地址，适用于仓库子路径。

静态页面加载不依赖模型服务、第三方字体或图标 CDN。主动打开 AI 助手会访问 Coze 平台；图片来源链接访问学校网站。网页公开网址不要求访问者登录 GitHub，也不依赖开发者电脑开机。AI 对话的登录、额度及可用性由 Coze 平台控制。

GitHub Pages、访问者网络以及浏览器会影响可用性；不承诺永久在线或百分之百可用。保留仓库及 Pages 配置即可持续提供静态网页。
